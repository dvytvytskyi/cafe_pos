# 🖥️ Complete UI-Module Frontend to Backend (FE-BE) Connection Checklist

Цей документ відстежує стан підключення кожного окремого екрану, сторінки та модального вікна (UI-модуля) фронтенду на React до бази даних PostgreSQL через API Next.js. Окрім базових CRUD-операцій, тут зафіксовані всі фільтри, сортування, пошукові запити та календарні вибірки.

## 🗺️ Зали, Столи та POS-термінал
1. **Екран залів та столів (`TablesView.tsx`)** 
   * **Статус**: 🟢 Підключено
   * **API**: `GET /api/locations/[id]/layout`
   * **Деталі зв'язків**: Збереження координат столів, зон, перешкод у PostgreSQL.
   * **Тестування**: 
     * *Юніт*: `test-unit-tables-layout.ts`
       * Перевірка валідності масиву координат (координати мають бути в межах сітки).
       * Валідація відсутності накладання столів (collision detection).
       * Обробка виняткових значень (від'ємні координати, нульовий розмір столу).
     * *Інтеграційне*: `test-tables-layout.ts`
       * Збереження схеми залу через Prisma Transaction.
       * Робота Prisma upsert для локацій (створення локації автоматично, якщо вона відсутня).
       * Обробка помилок бази даних при некоректних foreign key зв'язках столів.
     * *Ручне*:
       * Перетягування столів у режимі редагування, збереження (клік "Save changes").
       * Повне очищення кешу браузера та LocalStorage -> повторне завантаження сторінки -> верифікація збережених координат.
